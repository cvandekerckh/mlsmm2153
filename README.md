# Welcome on Web Mining [MLSMM2153] repo !

The following repository contains different coding ressources linked to the Web Mining course. 

The repository contains exercises and ressources for the three major part of the course
- 1_data_collection : scripts related to data collection on the web
- 2_text_mining : scripts related to the process of transforming unstructured textual data
- 3_link_analysis : scripts related to the exploration and transformation of networks and graphs
