# Web Mining [MLSMM2153]

Ce dépôt contient les scripts et notebooks liés au cours **MLSMM2153 - Web Mining**.

Le site principal du cours est le **Moodle**, intitulé « MLSMM2153 - Web Mining » : https://moodle.uclouvain.be/course/view.php?id=5813

En plus de ce dépôt, le Moodle contient les supports de cours et l'énoncé du projet. C'est aussi la plateforme de référence pour la remise des rapports, des slides, etc.

## Contenu du dépôt

Le dépôt suit les trois grandes parties du cours :

- `1_data_collection` : collecte de données sur le web (lecture de fichiers, scraping, API, extraction de tableaux HTML)
- `2_text_mining` : transformation de données textuelles non structurées (tokenization, TF-IDF, embeddings, applications, analyse audio)
- `3_link_analysis` : exploration et analyse de réseaux et de graphes (matrices d'un graphe, centralités, similarités, PageRank, HITS)

Les données utilisées par les exercices se trouvent dans le dossier `data`, organisé selon les mêmes trois parties.

## Ressources

- Link analysis : la librairie [scikit-network](https://scikit-network.readthedocs.io/en/latest/) permet d'analyser des graphes en Python et de vérifier vos implémentations.
